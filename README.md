# NoteBuddy — AI Study Companion

An AI-powered app that turns any notes — pasted text, a PDF, a photo of handwritten notes, or even a spoken lecture — into a full study kit: a plain-language summary, key terms, flashcards, a quiz, a mind map, and a chat (by text or voice) you can ask follow-up questions to. All generated by Google's Gemini AI, with XP, streaks, and badges to make studying feel like a game.

**Live app**: https://note-buddy-wheat.vercel.app
**Live API**: https://notebuddy-backend-92m7.onrender.com

- **AI**: Google Gemini (free tier) — study kits, chat, mind maps, and audio transcription
- **Backend**: Python + FastAPI
- **Database + Auth**: Supabase (free tier), including Google sign-in
- **Frontend**: React + Tailwind CSS + Framer Motion
- **Hosting**: Vercel (frontend) + Render (backend), both free

### Features

- Paste text, upload a PDF/photo, or **record/upload audio** — NoteBuddy transcribes and understands all of it
- Summary, key terms, flashcards, quiz, and a **mind map**, all explained at a level you choose (kid / beginner / student)
- Chat about your material by typing **or by voice** (mic button, browser speech recognition)
- **Spaced-repetition review** (SM-2 algorithm) to keep what you've learned from fading
- **Combine notes** into one merged study kit before an exam covering several lectures
- **Read-aloud** (text-to-speech) and **PDF export** of any study kit
- Search and subject tags, XP/streaks/**badges**, and an onboarding spotlight tour
- Sign in by email/password or **Google**, with a proper account menu (name, email, log out)

## 1. Before you start

You need three free accounts/tools set up. Do these first:

1. **Node.js** (v18+) and **Python** (3.11 recommended — newer versions can fail to build some backend dependencies) installed on your machine.
2. A **Gemini API key** — go to https://aistudio.google.com/app/apikey, sign in with Google, click "Create API key". Copy it somewhere safe.
3. A **Supabase project** — go to https://supabase.com, sign up free, click "New project". Once it's created:
   - Go to **Project Settings → API**. Copy the **Project URL**, the **anon public key**, and the **service_role key** (keep this one secret).
   - Go to **SQL Editor → New query**, paste the contents of `backend/supabase_schema.sql` (included in this project), and click **Run**. This creates the `notes`, `profiles`, and `flashcard_progress` tables.

## 2. Open this project in VS Code

Clone or unzip the project, then in VS Code: **File → Open Folder** → select the `Notebuddy` folder.

You'll run the backend and frontend in **two separate terminals**. Open a terminal with `` Ctrl+` `` (or Terminal → New Terminal), and you can split it into two using the split-terminal icon top-right of the terminal panel.

---

## 3. Backend setup (Terminal 1)

Paste these one at a time into **Terminal 1**:

```bash
cd backend
python -m venv venv
```

Activate the virtual environment — **pick the line for your OS**:

```bash
# macOS / Linux
source venv/bin/activate

# Windows (PowerShell)
venv\Scripts\Activate.ps1
```

Then install dependencies and set up your keys:

```bash
pip install -r requirements.txt
cp .env.example .env
```

Now open the new `backend/.env` file in VS Code and paste in your real **Gemini API key**, **Supabase URL**, and **Supabase service_role key** (from Step 1).

Start the backend:

```bash
uvicorn app.main:app --reload --port 8000
```

You should see `Uvicorn running on http://127.0.0.1:8000`. Leave this terminal running. You can check it worked by opening http://localhost:8000/docs in your browser — you'll see the interactive API docs.

---

## 4. Frontend setup (Terminal 2)

In a **second terminal**:

```bash
cd frontend
npm install
cp .env.example .env
```

Open the new `frontend/.env` file and paste in your **Supabase URL** and **anon public key** (from Step 1). Leave `VITE_API_BASE_URL` as `http://localhost:8000`.

Start the frontend:

```bash
npm run dev
```

Open the URL it prints (usually http://localhost:5173) in your browser. Sign up for an account, and you're in!

## 6. Google sign-in setup (one-time)

"Continue with Google" needs a real OAuth client — the button is already wired up, this just switches it on:

1. **Google Cloud Console** (https://console.cloud.google.com) → create a project (e.g. `NoteBuddy`)
2. **APIs & Services → OAuth consent screen** → External → fill in app name + your email → save through to the dashboard
3. **Google Auth Platform → Branding** → fill in **Application home page** and **Application privacy policy link** (any reachable URL works — a simple hosted page is enough), then **Save**
4. **Google Auth Platform → Clients → Create OAuth client**:
   - Type: **Web application**
   - **Authorized JavaScript origins**: `http://localhost:5173` and your live frontend URL (e.g. `https://note-buddy-wheat.vercel.app`)
   - **Authorized redirect URIs**: `https://YOUR-SUPABASE-PROJECT.supabase.co/auth/v1/callback` (find your project ref in the Supabase URL)
   - Click **Create** — copy the **Client ID** and **Client Secret** shown
5. **Supabase → Authentication → Providers → Google** → enable it → paste in the Client ID and Client Secret → **Save**
6. **Google Auth Platform → Audience** → either **Publish app** (so anyone can sign in — first-time users see a one-click "unverified app" warning since the app isn't Google-reviewed, which is normal and fine for a demo) or add specific **Test users** by email if you'd rather keep it restricted
7. **Supabase → Authentication → URL Configuration** → set **Site URL** to your live frontend URL, and add `https://YOUR-LIVE-URL/**` under **Redirect URLs**

## 8. Deploying for free (so judges can use it live)

### Backend → Render

1. Go to https://render.com, sign up free, connect your GitHub.
2. **New → Web Service** → pick your `NoteBuddy` repo.
3. Set:
   - **Root Directory**: `backend`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
4. Under **Environment**, add `GEMINI_API_KEY`, `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `FRONTEND_ORIGIN` (your Vercel URL once you have it), and `PYTHON_VERSION` = `3.11.9` (newer Python versions can fail to build some dependencies on Render).
5. Deploy. Copy the URL Render gives you (e.g. `https://notebuddy-backend-92m7.onrender.com`).

### Frontend → Vercel

1. Go to https://vercel.com, sign up free, connect your GitHub.
2. **Add New → Project** → pick your `NoteBuddy` repo.
3. Set **Root Directory** to `frontend`.
4. Under **Environment Variables**, add `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, and `VITE_API_BASE_URL` (your Render URL from above).
5. Deploy. Vercel gives you a live URL like `https://note-buddy-wheat.vercel.app` — that's what you demo/submit.
6. Go back to Render and update `FRONTEND_ORIGIN` to this Vercel URL, so CORS allows it.
7. Follow **Step 6** above (Google sign-in setup) to add this live URL to Google Cloud and Supabase too.

> Render's free tier "sleeps" after inactivity and takes ~30-60 seconds to wake up on the first request — worth knowing before a live demo, so hit it once a few minutes before you present.
