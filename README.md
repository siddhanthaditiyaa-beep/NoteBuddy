# NoteBuddy — AI Study Companion

An AI-powered app that turns any notes (pasted text, PDF, or a photo of handwritten notes) into a full study kit: a plain-language summary, key terms, flashcards, a quiz, and a chat you can ask follow-up questions to — all generated by Google's Gemini AI, with XP/streaks to make studying feel like a game.

- **AI**: Google Gemini (free tier)
- **Backend**: Python + FastAPI
- **Database + Auth**: Supabase (free tier)
- **Frontend**: React + Tailwind CSS + Framer Motion
- **Hosting**: Vercel (frontend) + Render (backend), both free

---

## 1. Before you start

You need three free accounts/tools set up. Do these first:

1. **Node.js** (v18+) and **Python** (3.10+) installed on your machine.
2. A **Gemini API key** — go to https://aistudio.google.com/app/apikey, sign in with Google, click "Create API key". Copy it somewhere safe.
3. A **Supabase project** — go to https://supabase.com, sign up free, click "New project". Once it's created:
   - Go to **Project Settings → API**. Copy the **Project URL**, the **anon public key**, and the **service_role key** (keep this one secret).
   - Go to **SQL Editor → New query**, paste the contents of `backend/supabase_schema.sql` (included in this project), and click **Run**. This creates the `notes` and `profiles` tables.

---

## 2. Open this project in VS Code

Unzip the project, then in VS Code: **File → Open Folder** → select the `notebuddy` folder.

You'll run the backend and frontend in **two separate terminals**. Open a terminal with `` Ctrl+` `` (or Terminal → New Terminal), and you can split it into two using the split-terminal icon top-right of the terminal panel.

---

## 3. Backend setup (Terminal 1)

Paste these one at a time into **Terminal 1**:

```bash
cd backend
python -m venv venv
```

Activate the virtual environment — **pick the line for your OS**:

```bash
# macOS / Linux
source venv/bin/activate

# Windows (PowerShell)
venv\Scripts\Activate.ps1
```

Then install dependencies and set up your keys:

```bash
pip install -r requirements.txt
cp .env.example .env
```

Now open the new `backend/.env` file in VS Code and paste in your real **Gemini API key**, **Supabase URL**, and **Supabase service_role key** (from Step 1).

Start the backend:

```bash
uvicorn app.main:app --reload --port 8000
```

You should see `Uvicorn running on http://127.0.0.1:8000`. Leave this terminal running. You can check it worked by opening http://localhost:8000/docs in your browser — you'll see the interactive API docs.

---

## 4. Frontend setup (Terminal 2)

In a **second terminal**:

```bash
cd frontend
npm install
cp .env.example .env
```

Open the new `frontend/.env` file and paste in your **Supabase URL** and **anon public key** (from Step 1). Leave `VITE_API_BASE_URL` as `http://localhost:8000`.

Start the frontend:

```bash
npm run dev
```

Open the URL it prints (usually http://localhost:5173) in your browser. Sign up for an account, and you're in!

---

## 5. Set up the demo account (one-time)

The Login page has a **"Try the demo account"** button for judges/testers — it needs an actual account to exist once:

1. Go to the Signup page in your running app and create an account with:
   - Email: `demo@notebuddy.app`
   - Password: `Demo1234!`
2. Confirm that account's email the same way you did your own (via the confirmation email, or by turning off "Confirm email" in Supabase Auth settings).

That's it — from then on, every time anyone logs in with the demo button, the app automatically wipes that account's previous notes and shows the onboarding tour again, so it's always a clean first-time demo.

## 7. Deploying for free (so judges can use it live)

### Backend → Render

1. Go to https://render.com, sign up free, connect your GitHub.
2. **New → Web Service** → pick your `notebuddy` repo.
3. Set:
   - **Root Directory**: `backend`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
4. Under **Environment**, add `GEMINI_API_KEY`, `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, and `FRONTEND_ORIGIN` (set this to your Vercel URL once you have it from the next step — you can update it after).
5. Deploy. Copy the URL Render gives you (e.g. `https://notebuddy-api.onrender.com`).

### Frontend → Vercel

1. Go to https://vercel.com, sign up free, connect your GitHub.
2. **Add New → Project** → pick your `notebuddy` repo.
3. Set **Root Directory** to `frontend`.
4. Under **Environment Variables**, add `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, and `VITE_API_BASE_URL` (set this to your Render URL from above).
5. Deploy. Vercel gives you a live URL like `https://notebuddy.vercel.app` — that's what you demo/submit.
6. Go back to Render and update `FRONTEND_ORIGIN` to this Vercel URL, so CORS allows it.

> Render's free tier "sleeps" after inactivity and takes ~30-60 seconds to wake up on the first request — worth knowing before a live demo, so hit it once a few minutes before you present.

## Project structure

```
notebuddy/
├── backend/
│   ├── app/
│   │   ├── main.py              # FastAPI app + CORS
│   │   ├── config.py            # env var loading
│   │   ├── routers/             # /api/notes, /api/chat, /api/user endpoints
│   │   └── services/
│   │       ├── extraction.py    # PDF/OCR text extraction
│   │       ├── gemini_service.py # all AI prompt logic
│   │       └── supabase_client.py
│   ├── requirements.txt
│   ├── .env.example
│   └── supabase_schema.sql      # run this in Supabase SQL Editor
└── frontend/
    ├── src/
    │   ├── pages/                # Landing, Login, Signup, Upload, Results, Dashboard
    │   ├── components/           # FlashcardDeck, Quiz, ChatPanel, XPBar, etc.
    │   ├── context/AuthContext.jsx
    │   └── lib/                  # api.js, supabaseClient.js
    └── .env.example
```
